# Shmotix — спецификация

## Цель
Перевод текста (в первую очередь субтитров) из выбранной области экрана в реальном времени,
маленькими локальными моделями. Платформы: macOS и Windows (v1), дальше — Linux; Xbox — см. ниже.

## Пользовательский сценарий
1. Запускаю приложение — появляется рамка поверх всех окон.
2. Перетаскиваю и растягиваю рамку на область субтитров.
3. Под рамкой в полосе показывается перевод, обновляется при смене субтитра.

## Архитектура
```
 Tauri-окно (прозрачное, always-on-top)          Rust-поток, каждые 500 мс
 ┌──────────────────────────────┐   позиция   ┌─────────────────────────────┐
 │  рамка = «дырка» для захвата │ ──────────▶ │ xcap: снимок монитора, crop │
 ├──────────────────────────────┤             │ ocrs: детекция+распознавание│
 │  полоса с переводом  ◀───────┼── event ─── │ тот же текст? → кэш         │
 └──────────────────────────────┘ "subtitle"  │ CTranslate2: перевод        │
                                              └─────────────────────────────┘
```

| Слой | Технология | Размер |
|---|---|---|
| UI | Tauri 2, статичный HTML без сборщика | ~10 МБ бинарь |
| Захват | `xcap` | — |
| OCR | `ocrs` (rten, чистый Rust) | ~12 МБ |
| Перевод | `ct2rs` (CTranslate2) + модели Argos/Opus-MT + SentencePiece | ~100 МБ на пару |

Код: `src-tauri/src/engine.rs` (OCR+перевод, без GUI), `src-tauri/src/lib.rs` (окно, захват, цикл),
`ui/index.html` (рамка и полоса).

## Ограничения v0.1
- OCR `ocrs` умеет только латиницу → исходный язык: en/fr/de/es и т.п. Японский/китайский — нужен
  другой OCR (PaddleOCR через `ort`).
- Пара языков одна, задаётся `SHMOTIX_PAIR`; модели качаются скриптом, не из приложения.
- Захватывается весь монитор и обрезается.
- Цифры BORDER/BAR продублированы в `lib.rs` и `index.html`.

## Роадмап
1. **v0.2 UX**: выбор языков в UI, загрузка моделей из приложения, хоткей «скрыть/показать»,
   запоминание позиции рамки, режим «перевод поверх субтитров» вместо полосы.
2. **v0.3 качество**: предобработка (контраст/бинаризация под игровые шрифты), склейка
   фраз между кадрами, пропуск кадра если пиксели не изменились (дешевле OCR).
3. **v0.4 языки**: PaddleOCR (CJK) через `ort`; опционально маленькая LLM (Qwen/Gemma 1B GGUF)
   для перевода с контекстом и сленгом.
4. **Дистрибуция**: GitHub Actions матрица mac/win, подпись и нотаризация macOS, инсталлятор MSI.

## Xbox
Сторонние оверлеи на консоли запускать нельзя. Реалистичные пути: ПК с картой захвата
(приложение работает поверх окна захвата — уже сейчас), или мобильное приложение с камерой
(ядро `engine.rs` переносимо на iOS/Android через Tauri mobile).
